# Cifrado Asimetrico RSA

## Acerca de

Aplicacion web de un solo archivo que demuestra el principio del cifrado asimetrico mediante la generacion de un par de claves RSA, el cifrado de un mensaje con la clave publica y el descifrado con la clave privada. Ilustra de forma educativa como dos partes pueden comunicarse de forma confidencial sin compartir la clave secreta, utilizando la Web Crypto API del navegador. Entorno exclusivo del navegador; sin servidor, ni base de datos, ni almacenamiento persistente.

## Caracteristicas principales

- Generacion de claves RSA mediante la Web Crypto API del navegador (RSA-OAEP).
- Cifrado de mensajes con la clave publica y descifrado con la clave privada, en el lado del cliente.
- Exportacion e importacion de claves en formato JWK como archivos JSON descargables.
- Interfaz responsiva con HTML5 y TailwindCSS mediante CDN.
- Sin servidor, base de datos, persistencia de datos ni almacenamiento de sesion.

## Stack tecnologico

| Categoria | Tecnologia |
|-----------|------------|
| Frontend | HTML5, JavaScript (Web Crypto API), TailwindCSS (CDN) |
| Criptografia | RSA-OAEP (Web Crypto API) |
| Navegador | Chrome, Edge, Firefox, Safari con soporte de Web Crypto API |
